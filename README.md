# Dev Meme Studio

개발자/취준생/직장인이 이미지와 문구를 조합해 밈 카드를 만들고 다운로드할 수 있는 무로그인 웹 이미지 편집 도구입니다.

로그인, 서버, DB 없이 동작하는 **정적 HTML 파일 하나**로 이루어져 있습니다.

## 실행 방법

- 로컬: `dev-meme-studio.html` 파일을 브라우저로 열면 바로 동작합니다.
- 배포: 이 저장소를 GitHub Pages로 배포하면 별도 서버 설정 없이 그대로 서비스할 수 있습니다.

## 사용법

1. 첫 화면에서 기본 템플릿(BUG/CODE/STUDY/INTERVIEW/OFFICE/POV) 중 하나를 선택하거나 "직접 만들기"로 시작합니다.
2. 편집기에서 배경 이미지, 이모지/스티커, 텍스트를 추가하고 위치·크기·색상을 조정합니다.
3. 화면비(1:1 / 4:5 / 9:16)를 선택합니다.
4. PNG 또는 JPEG로 다운로드합니다.

## 템플릿 저장 / 불러오기

서버나 브라우저 저장소(localStorage 등)를 사용하지 않습니다. 대신 **JSON 파일**로 저장합니다.

- "템플릿 저장"을 누르면 현재 템플릿이 JSON 파일로 다운로드됩니다.
- 나중에 다시 쓰려면 "JSON Import"에서 그 파일을 불러오면 됩니다.
- "내 템플릿" 목록은 현재 탭에서만 유지되며, 새로고침하면 사라집니다. 보관하려면 반드시 JSON 파일을 내려받아 두세요.

## 주요 기능

- 이미지/이모지/텍스트 자유 배치, 크기 조절
- 텍스트 글자 크기·색상·자동 줄바꿈 여부 설정
- 잘못된 파일/JSON 입력 시 기존 작업 유지 (안전한 거부)
- 미리보기와 다운로드 결과 동일하게 렌더링

## 제한 사항

- 로그인, 회원가입, 서버 DB, SNS 연동 없음
- 여러 사용자 간 템플릿 공유 기능 없음 (각자 JSON 파일로 개별 보관)
